# TravelMate · 行迹

一个会在尽量保留原计划的前提下，根据用户即时反馈、位置、预算和天气进行局部调整的旅行 Agent。

## 当前演示

当前版本使用杭州三日游模拟数据，重点展示：

- 文字行程与交互式路线地图联动
- 点击特色景点标记查看沉浸式详情
- 以“最小改动”原则替换单个景点
- 旅行预算记录与剩余预算提示
- 可编辑的 Agent Workflow
- 景点事实、个人偏好、行程约束和旅行记忆知识库
- 桌面端与移动端自适应布局

> 当前仓库是前端交互原型，不包含真实千问、高德 API Key，也不会在浏览器端保存密钥。

## 计划中的真实能力

- 千问：意图理解、候选方案解释与工具调用
- LangGraph：行程状态、确认节点、局部修改和长期记忆
- 高德地图：定位、POI、周边搜索、路线规划和地图展示
- 国内逐小时天气服务：未来几小时天气驱动的行程调整
- 后端数据库：预算、实际消费、偏好和修改历史

## 本地运行

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev
```

静态页面构建：

```bash
npm run build:pages
```

## 安全说明

真实 API Key 必须配置在后端环境变量中，不应写入仓库或发送到浏览器。GitHub Pages 仅用于当前无密钥的交互演示。
